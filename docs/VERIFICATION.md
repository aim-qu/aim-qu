## 连续页面与长版 README

交互页已改为连续滚动的 8 个区域，仍包含 9 项体验；点灯与记忆合并到同一个游戏区，切换时保留各自进度。真实浏览器已检查纵向排列、滚轮移动、区域导航、两种游戏完成和切换后的状态保持。390×844 视口下全部区域没有横向溢出。触摸模拟中，绘画画布默认允许纵向滚动；开启「指で描く」后才接管触摸绘画。AA 官方图片也出现在新闻区域下方。

README 使用九段完整操作动画、雨景横幅、六条官方新闻标题和完整 AA 图表。动画由实际页面操作录制，均提供减少动态时的静止替代，不在 README 内模拟可交互游戏。

## 水滴运动修订

旧版以固定列速度平移网格纹理，不具备逐滴状态、停顿或合并。已替换为独立水滴模拟与实例化渲染。新增五项检查覆盖滞留后释放、非匀速及横向移动、再次停住、合并体积守恒、避免高速穿越、固定步长可重复和数量上限。浏览器检查通过；固定种子的 9 秒场景记录了 11 次合并、37 次重新滞留，多数水滴保持附着。该记录验证程序行为，不是自然雨滴运动的实测数据。

检查图片、状态轨迹及帧率记录位于 `output/rain-qa/`。全局减少动态与单独暂停雨滴不会互相覆盖；手机版本仍无横向溢出。原雨景图片不变，仅重做动态水滴层。
